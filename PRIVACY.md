# Privacy Policy

This project is self-hosted software. It does not collect, store or transmit
any personal data to the project maintainers.

- All watched files and logs remain on the machine where the software runs.
- Data is sent only to the cloud remote configured by the user (for example,
  the user's own Google Drive) through rclone.
- OAuth credentials and tokens are stored locally in the user's rclone
  configuration, readable only by that user.
- No telemetry, analytics or tracking is included.

Questions or requests: open an issue in this repository.
